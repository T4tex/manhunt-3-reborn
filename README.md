# MANHUNT 3 - Reborn

This repository hosts the GitHub Pages landing page for the fan game MANHUNT 3 - Reborn.

## Install and preview locally

1. Clone the repo.
2. Open the project folder.
3. Start a local web server from the repo root:

```bash
python3 -m http.server 8000
```

4. Open http://localhost:8000 in your browser.

## GitHub Pages deployment

1. In GitHub, open the repository.
2. Go to Settings -> Pages.
3. Under "Build and deployment", choose "Deploy from a branch".
4. Select the `main` branch and `/ (root)` folder.
5. Save.

Your site will be published at:

https://t4tex.github.io/manhunt-3-reborn/

## Animated background

The page is set to use the animated background image at:

`assets/manhunt-bg.gif`

Place your provided GIF in that folder with that exact filename to use it as the hero background.
